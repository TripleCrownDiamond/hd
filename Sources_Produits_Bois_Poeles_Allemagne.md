# Sources de produits — Bois de chauffage et poêles à bois

Date de vérification : 27 juillet 2026  
Marché ciblé : Allemagne

## Avertissement important

L’absence de watermark ne signifie pas qu’une image ou une description est libre de droits.

Avant de republier les contenus d’un fabricant, grossiste ou autre marchand :

- demander une autorisation écrite ;
- demander un accès revendeur ;
- demander un flux CSV, XML ou API ;
- vérifier les conditions d’utilisation ;
- conserver la preuve de l’autorisation ;
- réécrire les descriptions commerciales ;
- ne jamais modifier les valeurs techniques officielles ;
- ne jamais inventer une certification ;
- utiliser les photos du fournisseur réel pour le bois de chauffage.

# 7. Ordre recommandé

1. Contacter Seidel & Eckert et Schornsteinwelt Großhandel.
2. Demander les conditions revendeur à Spartherm, Camina & Schmid, Austroflamm, RIKA et Jøtul.
3. Obtenir un catalogue autorisé avec images et documents.
4. Vérifier chaque modèle dans HKI CERT et les documents fabricant.
5. Réécrire les descriptions commerciales sans modifier les données techniques.
6. Pour le bois, choisir le fournisseur réel avant de créer les produits.
7. Photographier le vrai conditionnement vendu.
8. Conserver les autorisations et les versions des documents.
